# Design Taste

When reviewing or validating UI changes for visual quality on a project whose
own design system isn't already covered by a more specific skill, read
`design-standards.md` for the full checklist (layout hierarchy, typography,
spacing, color/contrast, anti-slop rules, responsive behavior) and
`README.md` for how to adapt its generic rules (palette, component names,
spacing scale) to the project's actual design system documentation.
